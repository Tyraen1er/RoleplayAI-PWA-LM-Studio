# Client Mobile PWA - RoleplayAI

Ce dossier contient l'interface utilisateur Progressive Web App (PWA) conçue pour fonctionner sur tout navigateur moderne ou être installée sur mobile (iOS / Android).

## 📁 Fichiers

- `index.html` : Structure de l'interface (panneau de contrôle serveur, paramètres modèle, zone de chat, modales trackers et directives système).
- `index.css` : Thème sombre moderne, mise en page responsive et prise en charge du mode plein écran.
- `app.js` : Interactions dynamiques, requêtes API vers le backend FastAPI, synchronisation des trackers et gestion de l'historique de chat.
- `manifest.json` : Configuration PWA permettant l'installation de l'application sur smartphone.
